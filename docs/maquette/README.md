# Maquette de référence

`version-b-atelier.html` est la source de la version B « Atelier » du [canevas de maquettes](https://claude.ai/artifact/No7CzhiPhwbN7MpRCJQgYd), exportée telle quelle. Elle s'ouvre dans le canevas ; les images (adresses `/_blob/…`) n'y sont pas incluses.

`rendu-accueil.jpg` montre l'accueil du nouveau site, construit d'après cette maquette, à 1 440 px de large.

Écarts volontaires avec la maquette :

- logo SVG définitif (serre + mot « SAJE Art&Paysage ») à la place du mot provisoire ;
- légende du projet en haut à droite de chaque image du diaporama, et flèches précédent / suivant à côté des points ;
- bande « Missions » (cinq cartes) entre « À la une » et le bloc Démarche, pour le parcours collectivités du PRD ;
- sur mobile, l'encart passe sous l'image du diaporama et les commandes sous l'encart.
