SAJE – Art & Paysage

Modifier le site, pas à pas

Corriger un texte, changer une photo, ajouter un projet : tout se fait depuis votre navigateur, sur ordinateur comme sur téléphone. Aucun code, aucun logiciel.

Un texte ?Cliquez dessus, écrivez, puis « Enregistrer ».
Une photo ?Des boutons apparaissent sur l’image : Remplacer, Texte, Supprimer…
Un projet ?« Nouveau projet » dans le tableau de bord.

Après chaque « Enregistrer », la modification est en ligne au bout de 1 à 2 minutes. Rien n’est jamais perdu : toutes les versions précédentes sont conservées (voir « Revenir en arrière »).

1 Se connecter

À faire une seule fois par appareil : le navigateur s’en souvient ensuite.

  1. Ouvrez sajepaysage.fr/admin/ dans votre navigateur.

  2. Collez votre clé d’accès (un long code commençant par github_pat_, remis avec ce guide) dans le champ, puis cliquez sur Se connecter.

Sur un ordinateur partagéCliquez sur Se déconnecter (en haut à droite) en partant : cela efface la clé de l’appareil.

Le tableau de bord

C’est la page d’accueil de l’administration. Elle liste tous les contenus du site avec, pour chacun, un bouton Modifier sur la page (et EN pour la version anglaise). Les étiquettes indiquent si un projet est Publié ou Masqué, et si l’anglais est complet.

2 Modifier un texte

Le principe : on modifie le texte directement sur la page, comme dans un traitement de texte.

  1. Dans le tableau de bord, cliquez sur Modifier sur la page à côté de la page voulue.

    Vous pouvez aussi parcourir le site normalement : tant que vous êtes connectée, un bouton Modifier cette page apparaît en bas à droite de chaque page.

  2. Une barre noire s’affiche en haut de la page. Passez la souris sur un texte : il s’entoure d’un pointillé violet. Cliquez dedans et écrivez.

  3. Quand vous avez fini, cliquez sur Enregistrer dans la barre noire. Le bouton indique combien de modifications attendent d’être envoyées, par exemple « Enregistrer (3) ».

  4. Le message « Enregistré. En ligne dans environ 2 minutes » confirme l’envoi. Rechargez la page un peu plus tard pour voir le résultat.

Mettre en forme un descriptif

Quand vous cliquez dans un descriptif (le grand texte d’un projet, d’une mission, de la Démarche…), une petite barre apparaît au-dessus : G (gras), I (italique), Lien et Sans lien. Sélectionnez d’abord les mots concernés, puis cliquez sur le bouton.

  • Pour un lien : sélectionnez les mots, cliquez sur « Lien », collez l’adresse complète (elle doit commencer par https://).
  • Pour un nouveau paragraphe : touche Entrée.

Les champs de la fiche projet

Sous chaque projet, la fiche affiche le lieu, la date, le commanditaire, les partenaires et votre intervention. Un champ resté vide n’apparaît pas sur le site ; en mode édition, il s’affiche avec « À compléter ». Cliquez dessus pour le remplir.

Bon à savoir
  • Pour un titre ou un champ court, Entrée valide la saisie. Échap sort du champ.
  • Quand vous collez un texte copié ailleurs (Word, un e-mail…), seul le texte est gardé, sans sa mise en forme.
  • Annuler abandonne tout ce qui n’est pas enregistré ; Quitter sort du mode édition.

La version anglaise

Dans la barre noire, Passer en EN ouvre la même page en anglais, avec les mêmes outils. Les textes entourés d’un pointillé orange ne sont pas encore traduits : le site affiche alors le français à leur place. Cliquez dessus et écrivez la traduction.

3 Changer, ajouter ou retirer des photos

En mode édition, chaque image d’un projet porte une rangée de boutons.

BoutonCe qu’il fait
CouvertureChoisit l’image qui représente le projet : vignette dans la liste des projets, à l’accueil, et aperçu quand le lien est partagé.
← →Déplace l’image avant ou après sa voisine. La première image est la grande image en haut de la page.
TexteModifie la description de l’image (texte alternatif) et sa légende, en français et en anglais.
RemplacerRemplace la photo par une autre, en gardant sa place.
SupprimerRetire l’image du projet (après confirmation). Elle reste récupérable dans l’historique.

Ajouter des photos

  1. Tout en bas de la page du projet, cliquez sur « + Ajouter des images ».

  2. Choisissez une ou plusieurs photos à la fois. Sur téléphone, vous pouvez prendre une photo ou piocher dans la photothèque.

  3. Pour chaque photo, une fenêtre demande sa description (voir ci-dessous). Remplissez-la, puis Valider.

  4. Cliquez sur Enregistrer : les photos sont envoyées avec le reste.

Aucun besoin de préparer vos photosElles sont automatiquement réduites à une taille adaptée au site (2 400 pixels au plus) et leurs informations cachées — dont la position GPS — sont effacées avant l’envoi.

La description d’une image : obligatoire

Le texte alternatif en français décrit l’image pour les personnes qui ne peuvent pas la voir (lecteur d’écran) ; il s’affiche aussi quand l’image ne se charge pas, et aide le référencement. Il est obligatoire : le bouton Enregistrer refuse tant qu’une image n’en a pas.

Une phrase suffit, qui dit ce que l’on voit : « Allée de sable bordée de graminées, menant à des panneaux blancs », plutôt que « IMG_2043 » ou « photo du jardin ». La version anglaise et la légende (affichée sous l’image agrandie) sont facultatives.

L’IA vous propose la descriptionQuand vous ajoutez ou remplacez une photo, la fenêtre « Texte de l’image » s’ouvre avec une description déjà écrite en français et en anglais, rédigée par une IA d’après la photo et le titre de la page. Relisez-la toujours : corrigez un détail faux, ajoutez un nom ou un lieu que la photo ne dit pas. Le bouton Proposer un texte relance l’IA à tout moment ; si vous avez déjà écrit quelque chose, même en vrac, elle le corrige, le complète et le traduit sans rien retirer. Elle n’écrit jamais de légende à votre place : elle relit et traduit seulement la vôtre.

Sur les autres pages (accueil, Démarche, missions), les images n’ont que deux boutons : Texte et Remplacer.

4 Ajouter un nouveau projet

Un nouveau projet est d’abord créé masqué : personne ne le voit tant que vous ne l’avez pas publié. Vous pouvez donc le préparer tranquillement.

  1. Dans le tableau de bord, cliquez sur Nouveau projet.

  2. Saisissez le titre en français et cochez les catégories (ce sont les filtres de la page Projets : un projet peut en avoir plusieurs). Puis Créer le projet.

  3. Patientez environ 2 minutes. Le message « C’est en ligne. Ouverture de la page… » s’affiche, puis la page du projet s’ouvre toute seule en mode édition. (Si vous fermez l’onglet, retrouvez le projet dans la liste du tableau de bord.)

  4. Remplissez la page, comme au point 2 : accroche (la phrase d’introduction), descriptif, fiche (lieu, date…). Puis ajoutez les photos, comme au point 3. La première photo ajoutée devient la couverture ; vous pouvez en choisir une autre avec le bouton Couverture.

  5. Cliquez sur Réglages du projet (barre noire en haut), cochez « Publié (visible sur le site) » puis Appliquer.

  6. Cliquez enfin sur Enregistrer. Environ 2 minutes plus tard, le projet apparaît dans la liste des projets du site.

Avant de publierAjoutez au moins une photo : elle sert de vignette dans la liste. Un projet publié sans image s’afficherait avec une case vide.

Et ensuite ?

  • Masquer un projet sans le supprimer : Réglages du projet, décochez « Publié », puis Enregistrer. Il disparaît des listes ; vous pourrez le republier plus tard.
  • Les missions liées (dans les mêmes réglages) font apparaître le projet au bas de la page de chaque mission cochée.
  • L’anglais : Passer en EN dans la barre noire, puis traduisez le titre, l’accroche et le descriptif. Tant que ce n’est pas fait, la page anglaise affiche le français.

5 Réorganiser les projets et l’accueil

Ces réglages se font dans le tableau de bord, plus bas que la liste des contenus.

L’ordre des projets

Dans « Ordre des projets », déplacez chaque projet avec les flèches ↑ ↓ (ou en le faisant glisser, sur ordinateur), puis cliquez sur Enregistrer l’ordre. Les projets masqués restent dans la liste, marqués « Masqué ».

Le diaporama et les projets « À la une »

Dans « Page d’accueil » :

  • Diaporama : réordonnez les images ou retirez-en avec Retirer. Pour en ajouter une, ouvrez « Ajouter une image au diaporama », choisissez un projet puis cliquez sur la photo voulue.
  • À la une : choisissez dans les trois listes les projets mis en avant sous le diaporama.
  • Puis cliquez sur Enregistrer l’accueil.

6 Revenir en arrière

En bas du tableau de bord, l’historique liste les 20 dernières modifications. Ouvrez-en une : les fichiers concernés s’affichent, avec un bouton Revenir à cette version qui rétablit le fichier tel qu’il était juste après cette modification. C’est aussi le moyen de récupérer une image ou un projet supprimé par erreur.

7 Si quelque chose ne va pas

Ce que vous voyezQue faire

« …a été modifié ailleurs depuis l’ouverture de cette page »La même page a été modifiée par quelqu’un d’autre, ou dans un autre onglet. Pour ne rien écraser, rien n’a été enregistré : copiez votre texte, rechargez la page, puis recommencez.
« Le texte alternatif est obligatoire »Une image n’a pas de description. Cliquez sur son bouton Texte et remplissez le champ français.
Ma modification n’apparaît pasAttendez 2 minutes, puis rechargez la page (sur téléphone : fermez et rouvrez l’onglet). Vérifiez dans le tableau de bord que la pastille est verte.
Pastille rouge « Erreur lors de la mise en ligne »Vos modifications sont enregistrées, mais le site n’a pas pu être reconstruit. Prévenez la personne qui gère le site.

Annexe · Créer ou renouveler la clé d’accès

Pour la personne qui gère le site. La clé est valable un an ; le tableau de bord prévient Alice 30 jours avant son expiration.

  1. Depuis le compte GitHub qui possède le dépôt du site, ouvrez github.com/settings/personal-access-tokens et cliquez sur Generate new token.

  2. Renseignez :

    • Token name : Site SAJE
    • Expiration : 1 an
    • Repository access : Only select repositories, puis le dépôt du site
    • Repository permissions : Contents → Read and write ; Actions → Read-only (pour afficher l’état de la mise en ligne)

  3. Cliquez sur Generate token, copiez le code github_pat_… (GitHub ne le montrera plus) et transmettez-le à Alice par un moyen privé.

Cette clé donne le droit de modifier le dépôt du site.Elle ne doit pas être publiée ni envoyée à d’autres personnes. En cas de doute, supprimez-la sur la même page GitHub : elle cesse aussitôt de fonctionner, et une nouvelle peut être créée.
